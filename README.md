# privacy-policy

Public privacy policy for Tony Cheng’s apps and services.

**Privacy Policy URL:** https://tonyp222happy.github.io/privacy-policy/

The policy itself is the static page [`index.html`](index.html). This README only points to that page. GitHub Pages publishes the `main` branch from the repository root. The [`.nojekyll`](.nojekyll) file tells GitHub Pages to serve the HTML as-is.

To request deletion of personal data, open a [GitHub Issue](https://github.com/tonyp222happy/privacy-policy/issues).
