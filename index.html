Privacy Policy

This page is the privacy policy of Tony Cheng. It explains how personal data is handled for the apps and services Tony Cheng operates. You can read it without signing in.

This policy applies to Tony Cheng’s apps and services, including apps that use Meta platforms (Facebook, Instagram, and Threads) through the Graph API or other Meta developer products.

The operator of those apps and services is Tony Cheng.

Personal data that may be processed

Tony Cheng processes only personal data that you authorize through Meta, or that you otherwise provide. Data you have not authorized and have not provided is not collected for these apps.

  • Data you authorize through Meta. When you connect a Meta account and approve access, Meta may send the app the personal data covered by that approval. What is included depends on the permissions you grant on Meta’s own authorization screen. Data you do not authorize is not received from Meta.
  • Data you otherwise provide. This is information you choose to give to an app or service. An example is content you submit so that a feature you have permitted can publish or manage it.

Tony Cheng does not buy personal data, and does not take personal data from Meta beyond the access you authorize.

How personal data is processed, and for what purposes

Personal data is used only to provide the features you have permitted.

For example, if you authorize an app to publish or manage content, the data needed for that feature is used to publish or manage the content you authorized. It is not used for a different purpose.

Where a feature you permitted needs data to be sent to a Meta platform (for example, content you asked the app to publish), that data is transmitted to Meta so the feature can be carried out. Meta then handles it under Meta’s own terms.

Personal data is processed in order to:

  • provide the features you have permitted, such as publishing or managing content you authorized;
  • respond to you about that data, including a request to access, correct, or delete it.

Personal data is not sold. It is not shared with other parties for their own marketing, and it is not used for a purpose you did not permit. It may be disclosed if the law requires a disclosure.

How long personal data is kept

Personal data is kept only for as long as it is needed to provide the features you have permitted, to handle a request you make about that data, or to meet a legal obligation to keep a particular record. When it is no longer needed, it is deleted or de-identified. It is not kept for unrelated later uses.

How to request deletion of your data

To request deletion of your personal data, or to request access or correction, open a GitHub Issue:

https://github.com/tonyp222happy/privacy-policy/issues

Name the app or service you used and what you want deleted, accessed, or corrected. You may include a Meta account name or user identifier if you are comfortable sharing it. Do not include passwords, access tokens, or other sign-in credentials.

Issues in this public repository can be read by anyone. Include only what is needed to identify the request. If you do not want an identifier posted in public, say that in the Issue.

Tony Cheng will review the request and may ask for what is reasonably needed to confirm that it relates to you, so that another person cannot have your data deleted. Personal data held about you for the apps and services covered by this policy will then be deleted, except where the law requires a particular record to be kept.

You can also remove an app’s access in your own Meta account settings. Meta provides that control (often with the settings for apps and websites, or whatever equivalent Meta currently offers). Removing access stops further data from being received from Meta for that account. It does not by itself delete data already held. To ask for deletion of data already held, use the GitHub Issue above.

Hong Kong Personal Data (Privacy) Ordinance

Where the Personal Data (Privacy) Ordinance (Cap. 486) of Hong Kong applies, Tony Cheng handles personal data in line with its data protection principles. Those principles include collecting data lawfully and fairly, using it only for the purpose for which it was collected or a directly related purpose, keeping it accurate and no longer than necessary, protecting it, being open about these practices, and your right to request access and correction. You may also request deletion as described above. This page is the notice of these practices.

Security

Tony Cheng takes reasonable care to protect personal data against unauthorized access, loss, and misuse. No method of holding or sending data is completely secure.

Changes to this policy

This policy may be updated if these practices change. The last-updated date is 14 November 2026. The current policy is the text on this page.

私隱政策

本頁是 Tony Cheng 的私隱政策，說明 Tony Cheng 營運的應用程式及服務如何處理個人資料。你無需登入即可閱讀。

本政策適用於 Tony Cheng 的應用程式及服務，包括透過 Graph API 或其他 Meta 開發者產品使用 Meta 平台（Facebook、Instagram 及 Threads）的應用程式。

這些應用程式及服務的營運者是 Tony Cheng。

可能處理的個人資料

Tony Cheng 只處理你透過 Meta 授權的個人資料，或你另行提供的資料。你沒有授權、亦沒有提供的資料，不會為這些應用程式而被收集。

  • 你透過 Meta 授權的資料。 當你連接 Meta 帳戶並批准存取後，Meta 可按該項批准向應用程式提供所涵蓋的個人資料。實際包括哪些資料，取決於你在 Meta 自己的授權畫面上授予的權限。你沒有授權的資料，不會從 Meta 收到。
  • 你另行提供的資料。 這是你選擇向應用程式或服務提供的資料。例如你提交內容，以便一項你已允許的功能發佈或管理該內容。

Tony Cheng 不會購買個人資料，亦不會向 Meta 取得超出你所授權範圍的個人資料。

如何處理個人資料，以及處理目的

個人資料只用於提供你已允許的功能。

例如，如果你授權應用程式發佈或管理內容，為該功能所需的資料只會用於發佈或管理你所授權的內容，不會用於其他目的。

如果你允許的功能需要把資料傳送到 Meta 平台（例如你要求應用程式發佈的內容），該等資料會傳送給 Meta，以便完成該功能。其後由 Meta 按其自身條款處理。

處理個人資料的目的是：

  • 提供你已允許的功能，例如發佈或管理你授權的內容；
  • 就該等資料回應你，包括查閱、改正或刪除的要求。

個人資料不會被出售，不會交予其他人士作其自身推廣，亦不會用於你未允許的目的。如法律要求披露，則屬例外。

個人資料會保留多久

個人資料只會在提供你已允許的功能、處理你就該等資料提出的要求，或履行必須保留某項紀錄的法律責任所需的期間內保留。不再需要時，會刪除或去除可識別身分的部分，不會為無關的日後用途而保留。

如何要求刪除你的資料

如要要求刪除你的個人資料，或要求查閱或改正，請開啟 GitHub Issue：

https://github.com/tonyp222happy/privacy-policy/issues

請說明你使用的應用程式或服務，以及你希望刪除、查閱或改正的內容。如果你願意，可以提供 Meta 帳戶名稱或用戶識別碼。請勿提供密碼、存取權杖或其他登入憑證。

本公開儲存庫的 Issue 任何人都可以閱讀。請只提供識別該要求所需的資料。如果你不希望在公開頁面貼上識別資料，請在 Issue 中說明。

Tony Cheng 會審視該要求，並可能請你提供合理所需的資料，以確認要求與你本人有關，避免其他人要求刪除你的資料。除法律規定必須保留的特定紀錄外，就本政策所涵蓋的應用程式及服務而持有的你的個人資料，其後會被刪除。

你亦可在自己的 Meta 帳戶設定中移除應用程式的存取權。該項控制由 Meta 提供（常見於應用程式及網站的設定，或以 Meta 當時提供的同等位置為準）。移除存取權後，便不會再就該帳戶從 Meta 收到進一步的資料。這本身不會刪除已經持有的資料。如要要求刪除已經持有的資料，請使用上述 GitHub Issue。

香港《個人資料（私隱）條例》

在香港《個人資料（私隱）條例》（第486章）適用的情況下，Tony Cheng 會按照該條例的保障資料原則處理個人資料。這些原則包括以合法及公平的方式收集資料、只把資料用於收集時的目的或直接有關的目的、保持資料準確且保留時間不超過需要、保障資料、就上述做法保持開放，以及你要求查閱及改正的權利。你亦可按上文要求刪除資料。本頁就是這些做法的說明。

保安

Tony Cheng 會採取合理措施，保護個人資料免受未經授權的存取、遺失及誤用。任何持有或傳送資料的方式都無法保證絕對安全。

本政策的更改

如果這些做法有變，本政策可能會更新。最後更新日期是 2026年11月14日。現行政策以本頁文字為準。
